# WestSummerlin
West Summerlin 

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

### Pages

- `/` — home
- `/3d-tour` — 360° view of an AI-generated Summerlin West scene (World Labs Marble), with a link to the full walkable 3D world. The panorama is self-hosted at `public/worlds/summerlin-west-pano.jpg` because the Marble viewer can't be embedded in an iframe.
